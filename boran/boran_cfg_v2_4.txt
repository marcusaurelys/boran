Authors:      Joel Ethan Batac

Last Updated:   06 August 2026

Changelog (2.3 -> 2.4):
  - Revised error handling's surface syntax (superseding the 2.2->2.3
    entry below, which is now out of date): there is no separate 'error'
    datatype after all. A caught value is just an ordinary string, so the
    'catch' clause takes a single untyped binding rather than a
    ':' <datatype> pair:
        try {
          throw "out of range";
        } catch (e) {
          print(e);
        }
    <try_catch_stmt> ::= 'try' <block> 'catch' '(' <identifier> ')' <block>
    <throw_stmt>     ::= 'throw' <expr>
    'throw' requires its <expr> to evaluate to a string (a static type
    error otherwise) and unwinds to the nearest enclosing 'catch', which
    binds it as a plain string local scoped to the catch block. Only
    THREE new reserved words: 'try', 'catch', 'throw' -- 'error' is not a
    keyword and remains available as an identifier.
  - In addition to an explicit 'throw', exactly three native runtime
    faults are now catchable the same way (as a string describing the
    fault) rather than always terminating the program:
      * division by zero (int or float, '/' or '%')
      * an invalid cast to a numeric type, i.e. 'as int'/'as float' on a
        non-numeric string (e.g. "abc" as int)
      * a null-pointer dereference ('*p' where p is null, or points at a
        freed cell)
    Every other runtime fault (array-index-out-of-bounds, calling a
    non-function value, an undeclared-variable reference that somehow
    reaches runtime, etc.) is still always fatal, try/catch or not --
    these three are a deliberate, curated subset, not a general
    exception mechanism. An uncaught throw (explicit or native) still
    terminates the program, same as any other uncaught runtime error.

Changelog (2.2 -> 2.3) [ORIGINAL ERROR-HANDLING DESIGN, SUPERSEDED ABOVE]:
  - Added dynamic heap allocation via a new 'new(...)' keyword-led primary
    expression: <new_expr>. Takes exactly one argument, an atomic literal
    value (int, float, char, string, or bool), allocates space for it on
    the heap, and evaluates to a pointer to that value:
        let number : int* = new(5)
    This only applies to the five scalar primitives. struct, enum, and
    array values are already heap-allocated by their own literal/instance
    forms, so 'new' is a static error when its argument's type is not one
    of int/float/char/string/bool.
  - Added error handling via <try_catch_stmt> and a new 'throw' statement,
    plus a new primitive datatype, 'error', to carry the caught value:
        try {
          throw "out of range";
        } catch (e : error) {
          print(e);
        }
    'throw' raises a value of type 'error' (constructed the same way a
    string is, via STRING_LIT, or from a runtime fault) and unwinds to the
    nearest enclosing 'catch'. The 'catch' clause declares a single typed
    binding, always of type 'error', scoped to its block. An uncaught
    throw (or uncaught runtime fault, e.g. divide-by-zero, out-of-bounds
    index, null-pointer dereference) terminates the program. 'try' and
    'catch' are now reserved words and can no longer be used as
    identifiers; likewise 'throw' and 'error'.

Changelog (2.1 -> 2.2):
  - Added 'range(...)' as a builtin, keyword-led primary expression (same
    grouping as 'print'/'input'), with three arities:
      range(end)               -- implicit start=0, step=1
      range(start, end)        -- implicit step=1
      range(start, end, step)
    Always evaluates to an ordinary int[] array, so it composes directly
    with the existing 'for x in <expr>' iteration form. Arguments must be
    int or float (floats truncate toward zero); a step of 0 is a runtime
    error. 'range' is now a reserved word and can no longer be used as an
    identifier.

Changelog (2.0 -> 2.1):
  - <for_repeat_stmt> no longer requires a trailing ';' in <stmt>. Every
    other block-terminated statement form (if_stmt, for_iter_stmt,
    for_while_stmt) needs no semicolon, since the closing block already
    marks the statement boundary; requiring one only for the repeat-until
    form was an unintentional inconsistency, not a parsing necessity. A
    trailing ';' is still accepted (not an error) for backward
    compatibility with existing source files.
  - Added explicit type casting via a new 'as' operator: <cast_expr>,
    sitting between <unary_expr> and <postfix_expr> in precedence (binds
    tighter than arithmetic, looser than the prefix unary forms). Casts
    chain left-associatively (`x as float as string`). Restricted to the
    five scalar primitives (int, float, char, string, bool); casting to
    or from struct/array/fn/enum/ptr types is a static type-mismatch
    error. A handful of primitive pairings (e.g. string -> int) can still
    fail at runtime if the value isn't actually convertible.

----------------------------------------------------------------
Notation
----------------------------------------------------------------
This specification uses Backus-Naur Form (BNF):

    <nonterminal>  ::=  production rule
    'terminal'            literal token, single-quoted
    A | B                 alternation (A or B)
    ε                     empty string / no token
    A*                    zero or more repetitions of A
    A+                    one or more repetitions of A
    UPPERCASE             lexical token supplied by the scanner
                           (e.g. INT_LIT, STRING_LIT)

Nonterminals are grouped below by category: Program Structure,
Declarations, Values & Literals, Expressions, Statements, and
Lexical Rules.
================================================================



<program> ::= <stmt_list>
<stmt_list> ::= <stmt> <stmt_list> | ε
<stmt> ::= <const_decl> ';'
         | <let_decl> ';'
         | <assign_stmt> ';'
         | <if_stmt>
         | <for_iter_stmt>
         | <for_while_stmt>
         | <for_repeat_stmt>
         | <return_stmt>
         | <expr> ';'
         | <block>
         | <break_stmt> ';'
         | <continue_stmt> ';'
         | <try_catch_stmt>
         | <throw_stmt> ';'

<block> ::= '{' <stmt_list> '}'

<const_decl> ::= 'const' <identifier> ':' <datatype> '=' <value>
               | 'const' <identifier> ':' <identifier> '=' <value>
               
<let_decl> ::= 'let' <identifier> ':' <datatype> '=' <value>
            | 'let' <identifier> ':' <datatype>
            | 'let' <identifier> ':' <identifier> '=' <value>
            | 'let' <identifier> ':' <identifier>

<datatype> ::= 'int' | 'float' | 'char' | 'string' | 'bool'
                          | <arr_type> | <fn_type> | <ptr_type>
                          | 'struct' | 'enum'

<arr_type> ::= <datatype> '[' INT_LIT ']'
<fn_type> ::= 'fn'
<ptr_type> ::= <datatype>'*'

# --- Values ---

<value> ::= <expr>
          | <arr_literal>
          | <struct_literal>
          | <struct_instance>
          | <enum_body>
          | <fn_literal>

<literal> ::= INT_LIT | FLOAT_LIT | CHAR_LIT | STRING_LIT | BOOL_LIT | 'null'

<arr_literal> ::= '[' <arr_elements> ']'
                | '[' ']'
<arr_elements> ::= <value> <arr_elements_tail>
<arr_elements_tail> ::= ',' <value> <arr_elements_tail> | ε

<struct_literal> ::= '{' <struct_field_inits> '}'
<struct_field_inits>    ::= <struct_field_init> <struct_field_inits_tail>
<struct_field_inits_tail> ::= ',' <struct_field_init> <struct_field_inits_tail> | ε
<struct_field_init> ::= <const_decl> ## same and immutable values across all instances 
                      | <let_decl> ## mutable values or state 

<struct_instance> ::= '{' <instance_fields_inits> '}'
<instance_fields_inits> ::= <instance_field_init> <instance_field_inits_tail> | ε
<instance_fields_inits_tail> ::= ',' <instance_field_init> <instance_fields_inits_tail> | ε
<instance_field_init> ::= <identifier> ':' <value>

<enum_body> ::= '{' <enum_variants> '}'
<enum_variants> ::= <enum_variant> <enum_variants_tail>
<enum_variants_tail> ::= ',' <enum_variant> <enum_variants_tail> | ε
<enum_variant> ::= <identifier>

<fn_literal> ::= '(' <param_list> ')' ':' <datatype> '=>' <block> | 
                 '(' <param_list> ')' '=>' <block> 

<param_list> ::= <params> |  ε
<params> ::= <param> <params_tail>
<params_tail> ::= ',' <param> <params_tail> | ε
<param> ::= <identifier> ':' <datatype>

# ---- Expressions ----

<expr>                   ::= <bool_expr>

<bool_expr>               ::= <bool_term> <bool_expr_tail>
<bool_expr_tail>          ::= '||' <bool_term> <bool_expr_tail> | ε

<bool_term>                ::= <bool_factor> <bool_term_tail>
<bool_term_tail>           ::= '&&' <bool_factor> <bool_term_tail> | ε

<bool_factor>               ::= '!' <bool_factor>
                              | <arith_expr> <rel_op_tail>
<rel_op_tail>                ::= <rel_op> <arith_expr> | ε
<rel_op>                     ::= '==' | '!=' | '<' | '>' | '<=' | '>='

<arith_expr>                  ::= <arith_term> <arith_expr_tail>
<arith_expr_tail>             ::= '+' <arith_term> <arith_expr_tail>
                                | '-' <arith_term> <arith_expr_tail>
                                | ε

<arith_term>                   ::= <unary_expr> <arith_term_tail>
<arith_term_tail>              ::= '*' <unary_expr> <arith_term_tail>
                                 | '/' <unary_expr> <arith_term_tail>
                                 | '%' <unary_expr> <arith_term_tail>
                                 | ε

<unary_expr>                    ::= '-' <unary_expr>
                                  | '++' <unary_expr>
                                  | '--' <unary_expr>
                                  | '*' <unary_expr>
                                  | '&' <unary_expr>
                                  | <cast_expr>

<cast_expr>                       ::= <postfix_expr> <cast_tail>
<cast_tail>                       ::= 'as' <datatype> <cast_tail> | ε

<postfix_expr>                   ::= <primary> <postfix_tail>
<postfix_tail>                   ::= '++' | '--' | ε

<primary>                         ::= <literal>
                                   | 'this' <this_tail>
                                   | '(' <expr> ')'
                                   | <io_stmt>
                                   | <range_expr>
                                   | <new_expr>
                                   | <identifier> <primary_tail>

<range_expr>                      ::= 'range' '(' <expr> <range_args_tail> ')'
<range_args_tail>                 ::= ',' <expr> <range_args_tail> | ε
                                   (capped at 3 total arguments: start, end, step)

<new_expr>                        ::= 'new' '(' <expr> ')'
                                   (single argument must be an atomic literal
                                    value: int, float, char, string, or bool;
                                    evaluates to a pointer to a fresh heap
                                    cell holding that value)

# Chaining

<primary_tail>                    ::= '(' <arg_list> ')' <chain_tail>
                                    | <chain_tail>

<this_tail>                       ::= '.' <identifier> <method_tail> <chain_tail>
                                    | ε

<chain_tail>                      ::= '[' <expr> ']' <chain_tail>
                                    | '.' <identifier> <method_tail> <chain_tail>
                                    | '(' <arg_list> ')' <chain_tail>
                                    | ε


<method_tail>                     ::= '(' <arg_list> ')' | ε

<arg_list>                          ::= <args> | ε
<args>                               ::= <expr> <args_tail>
<args_tail>                         ::= ',' <expr> <args_tail> | ε


# ---- Statements

<assign_stmt>                        ::= <lvalue> '=' <value>

<lvalue>                             ::= <identifier> <lvalue_tail>
                                       | 'this' <lvalue_tail>
                                       | '*' <lvalue>

<lvalue_tail>                        ::= '.' <identifier> <lvalue_tail>
                                       | '[' <expr> ']' <lvalue_tail>
                                       | ε

<if_stmt>                             ::= 'if' <bool_expr> <block>
                                       | 'if' <bool_expr> <block> 'else' <block>
                                       | 'if' <bool_expr> <block> 'else' <if_stmt>

<for_iter_stmt>                       ::= 'for' <identifier> 'in' <expr> <block>
<for_while_stmt>                      ::= 'for' <bool_expr> <block>
<for_repeat_stmt>                     ::= 'for' <block> <bool_expr>

<io_stmt>                             ::= 'print' '(' <expr> <print_args_tail> ')'
                                        | 'input' '(' <expr> <print_args_tail> ')' 

<print_args_tail>                     ::= ',' <expr> <print_args_tail> | ε

<return_stmt>                         ::= 'return' <expr>
                                       | 'return'

<break_stmt> ::= 'break'
<continue_stmt> ::= 'continue'

<try_catch_stmt>                      ::= 'try' <block> 'catch' '(' <identifier> ')' <block>
                                       (the catch binding is always a plain
                                        string -- no type annotation)

<throw_stmt>                          ::= 'throw' <expr>

# ---- Lexical -----

<identifier>                          ::= <letter> <alphanumeric>*
                                       | '_' <alphanumeric>+
<letter>                              ::= 'a'..'z' | 'A'..'Z'
<digit>                               ::= '0'..'9'
<alphanumeric>                        ::= <letter> | <digit> | '_'

WHITESPACE  ::=  [ \t\r\n]+            (ignored by scanner)
LINE_COMMENT ::= '#' <any>* <newline>  (ignored by scanner)
